# 1.2.0 release-route check: dev and template routes

Board: `docs/design/screens/key-screens.html` #not-found, "Dev and template routes". Worker 3f, 2026-10-05.

## What changed
- `apps/mobile/app/modal.tsx` (the Expo template) and `components/EditScreenInfo.tsx` (its only importer) are deleted, along with the `modal` Stack.Screen.
- `design-gallery` keeps its `if (!__DEV__) return <Redirect href="/" />`, and its Stack.Screen now sits in `<Stack.Protected guard={__DEV__}>`. In a release the navigator never registers the route, so a link to it falls back to the first screen: Home when signed in, sign-in when signed out.
- `tests-deno/release-routes.test.ts` pins this structurally (no `modal`, one design-gallery Screen directly inside the `__DEV__` guard, the redirect still there). It cannot run expo-router, so the behaviour was checked by hand:

## Checked by hand (iOS Simulator, Expo Go SDK 54, bundle served with `expo start --go --no-dev --minify`, so `__DEV__` is false)
| Leg | How | Result |
|---|---|---|
| Signed out, release bundle | open `exp://…/--/design-gallery` | onboarding / sign-in, the same as `origin/main` (no gallery) |
| Signed in, guard out | dev bundle, shell fixture `leagues`, the guard set to `false` | Home (league pill + tab bar), no gallery |
| Fixtures inert in release | `.env.local` held `EXPO_PUBLIC_SHELL_FIXTURE` and `EXPO_PUBLIC_JOIN_FIXTURE` during the `--no-dev` runs | both ignored: real sign-in flow |

The signed-in leg could not be run in a true release bundle: signing in needs credentials, and enabling the shell fixture outside `__DEV__` (to fake a session) was declined as weakening the dev-only gate. The guard-out mechanism was therefore exercised in a dev bundle.

Two early `--no-dev` runs of the signed-out link showed a blank screen, once with main's own `_layout.tsx` in the tree. It did not reproduce on the final code or on `origin/main` (three clean runs each); it is unexplained and probably Expo Go serving a stale bundle after Metro was swapped between trees (see MOBILE_SIMULATOR.md, "Stale bundle").
